# AniSearch

A desktop anime and manga search app built with Godot that pulls data from the AniList API. Type in a name, pick anime or manga, and get info, cover art, and a description instantly.

## Features
- Search any anime or manga by name
- Toggle between anime and manga search
- Displays title, episode/chapter count, score, status, genres, and description
- Shows cover art
- Uses the AniList GraphQL API (no API key needed)

## Download
Grab the latest `.exe` and `.pck` from the [Releases](../../releases) page.

## Run from source
1. Download [Godot 4](https://godotengine.org/)
2. Clone this repo
3. Open the project in Godot
4. Hit Play
