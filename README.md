# AniSearch
 
A desktop anime search app built with Godot that pulls data from the AniList API. Type in an anime name and get info and cover art instantly.
 
## Features
- Search any anime by name
- Displays title, episode count, score, status, and cover image
- Uses the AniList GraphQL API (no API key needed)
## Download
Grab the latest `.exe` from the [Releases](../../releases) page.
 
## Run from source
1. Download [Godot 4](https://godotengine.org/)
2. Clone this repo
3. Open the project in Godot
4. Hit Play
## Built with
- Godot 4 / GDScript
- [AniList API](https://anilist.gitbook.io/anilist-apiv2-docs)
